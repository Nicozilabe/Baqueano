Baqueano

A modern, interactive SSH Manager for your terminal. Manage, organize and connect to your SSH hosts with a beautiful TUI.

Download View on GitHub 
# launch the interactive manager
$ baq

# connect straight to a host
$ baq prod-server

# run a command remotely
$ baq prod-server uptime

# sync your host list across machines (optional)
$ baq drive sync

# update to the latest release
$ baq update

Features

Beautiful TUI

Navigate, search and connect to your hosts from an intuitive terminal interface.

Port forwarding

Set up Local, Remote and Dynamic (SOCKS) forwarding with guided forms and history.

Works with ~/.ssh/config

Reads and writes your standard SSH config, with automatic backups and validation.

SSH Include support

Organize hosts across multiple files and move hosts between them.

Optional Google Drive sync

Keep your host list in sync across machines through your own Google Drive. Nothing is sent to our servers.

Cross-platform

Single binary for Linux, macOS (Intel & Apple Silicon) and Windows.

Self-update

Install the latest release in place with baq update — downloads are verified against the release checksums.

Install

Unix / Linux / macOS

curl -sSL https://raw.githubusercontent.com/Nicozilabe/baqueano/main/install/unix.sh | bash

Windows (PowerShell)

irm https://raw.githubusercontent.com/Nicozilabe/baqueano/main/install/windows.ps1 | iex

Or download a prebuilt binary for your platform from the latest release.

Already installed? Update in place (downloads are verified against the release checksums):

baq update

Google Drive sync

Baqueano can keep your host list in sync across machines using your own Google Drive. The data is stored in a private, app-specific folder that only Baqueano can access, and it is never sent to any third party. No private keys are ever uploaded — only the host definitions from your SSH config.

baq drive login   # one-time authorization
baq drive sync    # merge local + remote and upload

See the Privacy Policy for details on how Baqueano accesses and uses your Google data.
